# Onboarding / Admin / Analytics

SaaS onboarding should get a tenant to first meaningful value, not force completion of every profile/config field. Distinguish account creation, tenant creation, invitation, setup prerequisites and activation milestones.

Admin/support tooling needs least privilege, searchable account context, safe diagnostic views, controlled entitlement/account actions and audit logs. Prefer scoped support actions over unrestricted impersonation; if impersonation exists, make entry/exit, visibility and audit explicit.

Measure activation, feature adoption, retained tenant activity, expansion, contraction and churn with clear user-vs-tenant metrics. Cohorts and plan changes matter. Instrumentation must respect privacy and avoid using a billing metric as a proxy for product value without context.
