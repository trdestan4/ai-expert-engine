# Motion System

## Job taxonomy

Motion must provide feedback, communicate state, preserve spatial continuity, reveal hierarchy, orient navigation, emphasize narrative, or express a rare branded signature.

## Intensity

- **Micro:** controls/local state; immediate and restrained.
- **Sectional:** reveal/recomposition; used selectively.
- **Signature:** rare, high-attention moments.

Keep surrounding UI calm around signature sequences.

## Timing

Shorter for direct feedback; longer only for meaningful spatial/narrative transitions. Use easing consistent with physical/brand character. Avoid identical stagger on every repeated list.

## Scroll

Default to native document flow. Sticky/pinned/parallax/horizontal sequences require clear narrative/spatial value and must preserve user control.

## Accessibility/performance

Provide reduced-motion equivalents, avoid essential information hidden behind animation, minimize layout-triggering animation, limit simultaneous layers, and redesign—not merely shrink—complex desktop motion for mobile.
