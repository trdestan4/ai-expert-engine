# Structured Data / Entities

Prefer JSON-LD when compatible with the existing stack. Select types/properties that accurately describe visible page content and current search-engine eligibility. Schema.org is a vocabulary, while search-engine rich results impose narrower requirements; do not confuse vocabulary validity with guaranteed presentation.

Validate markup, identifiers, product/offer relationships, organization/local-business data, breadcrumbs and software/application entities where relevant. Keep price, availability, ratings and variants consistent with the page and source-of-truth data. Never fabricate reviews, ratings or availability for markup.

Schema.org 30.0 is the current stable release as of 2026-03-19, but repository/tooling and search-engine support must be checked before using newly introduced properties. Structured data is supporting semantics, not a ranking shortcut.
