# Discovery / Merchandising / Analytics

Search and filters should match how customers describe products, not merely database column names. Define searchable fields, typo/synonym behavior where relevant, facets, multi-select semantics, sort options, zero-result recovery and large-catalog performance.

Category/collection structure should support merchandising and understandable navigation. Curated ranking can coexist with relevance, inventory and business rules, but hidden paid placement should be disclosed when required.

Commerce analytics should use stable product/variant/order identifiers and clear event semantics for list impression, product view, search/filter, add/remove cart, checkout step, purchase, refund and promotion. Prevent duplicate purchase events on reloads and provider retries. Use funnels as diagnostic evidence, not proof of causality.
