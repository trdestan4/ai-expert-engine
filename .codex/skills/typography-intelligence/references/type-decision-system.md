# Typography Decision System

Evaluate fonts by job and characteristics: x-height, width, stroke contrast, geometry/terminals, numeral quality, language coverage, weights/axes, small-size clarity, and loading footprint.

## Roles

Use only roles that add value: display, heading, body, UI/control, data/mono, metadata. One family can fill several roles.

## Hierarchy

Control size, weight, line-height, tracking, measure, case, and surrounding spacing. Do not rely on color alone.

For body copy, protect readable measure and comfortable line height. For large display type, design responsive line breaks/composition rather than only shrinking the size.

## Pairing

A second family must add functional or expressive contrast. Serif + sans is not automatically sophisticated. A single variable family may be stronger, faster, and more coherent.

## Performance

Load only used weights/styles, prefer variable fonts when they reduce payload/complexity, preload selectively, use metric-compatible fallbacks when layout shift matters, and verify target-language glyph coverage.
