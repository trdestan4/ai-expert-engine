# AI Design Cliché Library

This is a detection aid, not a blacklist. A pattern is weak when it appears because “premium/modern/AI/SaaS” triggered an automatic visual association rather than project-specific reasoning.

## Common cliché clusters

### Generic luxury
Black/navy + gold, high-contrast serif, thin gold rules, dark marble, glowing product pedestal, huge letter-spaced uppercase. Use only if brand/category evidence supports it and composition/material behavior is specific.

### Generic AI/tech
Purple-blue aurora gradients, neon cyan lines, glowing sphere/brain, particle networks, circuit motifs, glass panels, black background, gradient text. Ask what the technology actually does and derive a visual metaphor from that mechanism/user job.

### Generic SaaS
Centered headline/subhead/CTA, floating browser/dashboard screenshot, three equal feature cards, logo cloud, bento feature grid, testimonial cards, FAQ, gradient CTA. The content sequence may still be appropriate, but composition and evidence hierarchy must derive from the product.

### Generic “modern” UI
Everything rounded, pills everywhere, light gray canvas, cards around every section, random blur, soft shadows, icon-in-colored-square, repeated fade-up. Group content only when surface behavior or relationship requires it.

### Generic editorial premium
Oversized serif heading, tiny sans metadata, beige background, film grain, monochrome photography. Editorial language must match content rhythm, publication behavior and brand—not a fashion mood preset.

## Cliché detection tests

- **Prompt trigger:** would this choice still occur if the brief omitted “premium/modern/futuristic”? If not, it may be keyword-driven.
- **Swap test:** could a dental clinic, law firm and SaaS product use the same layout after changing copy/logo?
- **Reason test:** can the designer explain the choice using audience/product/category/content rather than adjective taste?
- **System test:** does the idea survive forms, tables, long content, mobile and error states?
- **Trend test:** if the named trend became unfashionable tomorrow, would the design logic remain valid?

## Transformation strategies

Do not merely avoid trends. Transform them:
- derive geometry from product artifacts/data/physical process;
- use category proof as composition;
- build color from real product/material/photo constraints;
- let content density create the grid;
- use motion to explain state/spatial relationships;
- make a brand asset influence framing/navigation instead of repeating a logo;
- create deliberate calm around one signature moment.

## False positives

A centered hero may be correct when the message is singular and short. Cards may be correct for independently actionable entities. Glass may be materially meaningful. Gold may be a heritage color. Flag only when rationale/evidence is absent or the pattern overwhelms product specificity.

## Maintenance

Clichés change. Treat this list as examples; the enduring rule is to detect choices generated by category/adjective autopilot. New trend patterns should be added only when repeated across unrelated products and when the engine can describe a better decision rule.
