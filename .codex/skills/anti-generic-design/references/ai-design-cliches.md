# AI / Template Design Clichés

Treat these as diagnostic signals, not automatic bans.

## Prestige clichés

- navy + gold = premium;
- black + gold + high-contrast serif = luxury;
- marble/metal textures without product relevance;
- excessive whitespace used as fake exclusivity.

## Tech/AI clichés

- purple/blue gradient everywhere;
- neon cyan on black;
- glowing mesh/orbs;
- random chrome 3D objects;
- generic network/node backgrounds;
- glass panels layered over gradient noise.

## Layout clichés

- badge → giant headline → two CTAs → floating dashboard hero;
- every section as rounded cards;
- arbitrary Bento grids;
- decorative metric cards;
- repetitive three-column feature rows;
- same About/Services/Why Us/Testimonials/CTA sequence regardless of narrative.

## Motion clichés

- every element fade-up on scroll;
- generic stagger on all cards;
- parallax without spatial/narrative meaning;
- exaggerated smooth scrolling that reduces control.

## Diagnostic question

If product name, logo, images, and colors were replaced, would the composition still be indistinguishable from thousands of templates? If yes, rebuild from product/content logic.
