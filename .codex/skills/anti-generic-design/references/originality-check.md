# Originality Check

Run this as a taste/originality gate after a coherent direction exists. It does not replace usability, accessibility or brand fit.

## Eight dimensions (0–2 each)

1. **Product-specific composition:** layout reflects real content/tasks rather than a generic section template.
2. **Brand-specific grammar:** recognizable rules survive logo removal.
3. **Typography rationale:** type behavior supports brand, language, content and UI jobs.
4. **Color rationale:** palette/semantic behavior fits brand/category/media/accessibility, not adjective clichés.
5. **Imagery coherence:** medium, lighting/crop/material and evidence role are controlled.
6. **Content/narrative specificity:** order and proof correspond to actual objections/jobs.
7. **Motion purpose:** feedback/spatial/narrative function exists; no animation-by-default.
8. **Responsive originality:** mobile preserves the concept through recomposition rather than generic stacking.

13–16 Pass; 10–12 Pass with notes; 6–9 Revise; 0–5 Reject. A zero in a critical dimension can still require revision despite total score.

## Adversarial checks

- hide logo;
- replace brand copy/images with a competitor;
- remove gradients/3D/effects and see whether concept survives;
- test a long translation and dense real data;
- inspect non-hero states;
- test reduced motion and dark/light mode where relevant;
- ask which decision would change if the product category changed.

## Review output

For each weak dimension state evidence, why it matters and a product-specific corrective direction. Do not prescribe “make it more unique.” Prefer: “The pricing section collapses to a standard 3-card SaaS pattern; derive comparison hierarchy from the actual usage metric and enterprise proof instead.”
