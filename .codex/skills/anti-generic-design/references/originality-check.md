# Originality Review

Score 0–2 per dimension:

- product-specific composition;
- brand-specific visual grammar;
- typography rationale;
- color rationale;
- imagery/art-direction coherence;
- content/narrative specificity;
- interaction/motion purpose;
- responsive originality without usability loss.

**13–16:** Pass. Strong authored system.
**10–12:** Pass with notes.
**6–9:** Revise. Too many defaults.
**0–5:** Reject direction.

Automatic review triggers: premium/luxury/modern/futuristic adjectives mapped directly to common palette/style, trend stacking, hero-only originality, or novelty that obscures controls.

Do not penalize familiar navigation, forms, ecommerce controls, accessibility conventions, or common patterns that materially improve comprehension.
