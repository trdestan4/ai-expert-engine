# Image Generation and Editing

Treat image generation as execution of an existing visual direction. Define subject, composition, camera/perspective, lighting, material/texture, palette, background, negative constraints and intended crop before generating. For asset families, document invariant traits so later outputs remain coherent.

Separate identity/content locks from stylistic freedom. When editing a supplied image, preserve explicitly locked face/body/object/logo/text/layout elements and modify only the requested regions. If exact preservation is technically uncertain, flag it rather than silently restyling the whole image.

Generate at an aspect ratio that matches the target composition where practical; repeated destructive crops usually indicate the master was designed incorrectly. Keep clean masters without overlaid UI copy when text will be rendered in HTML.

For product/brand imagery, consistency matters more than novelty per image. Match lens feel, camera height, shadow softness, background treatment, scale and color grade across the set. Build reference sheets/contact sheets when batches must look related.

Do not rely on generated typography, logos or regulated labels when exactness matters. Insert exact vector/live text in a controlled post-process instead.

Retouch non-destructively and preserve usable source resolution. Track source, prompt/reference notes and edit intent. Validate output at the actual UI size/background, not only zoomed in.

Before commercial reuse, confirm rights/provenance constraints of source material and generation service instead of assuming generated means unrestricted.
