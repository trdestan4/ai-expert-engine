# Landing Page / CRO

Diagnose conversion as a system: traffic intent, proposition relevance, comprehension, trust, offer, friction, usability, performance and measurement. A low conversion rate is not automatically a copy problem.

Landing pages should create a coherent decision path: problem/context, outcome, differentiation, product/service mechanism, proof, objections, commercial terms and CTA. Place proof close to the claim it supports. Use comparison, FAQ, guarantees and demos only when they reduce real uncertainty.

Experiments need a hypothesis, primary metric, guardrail metrics and enough exposure to interpret. Test meaningful strategic changes before button-color trivia. Never improve a metric by hiding costs, adding fake countdowns, trapping cancellation or degrading accessibility.
