# Product Decision Framework

Use when product directions compete.

Score only decision-relevant dimensions: user value, business value, evidence strength, implementation cost, maintenance cost, reversibility, trust/safety risk, and measurement clarity.

Prefer a smaller option set. Two or three materially different approaches are enough.

## Decision rules

- Prefer the option that best serves the primary user job, not the option with the most features.
- Treat irreversible data/business-model changes as higher-cost than reversible UI choices.
- Protect trust in high-consideration journeys before adding persuasion pressure.
- Reject speculative future-proofing unless a concrete near-term requirement justifies it.
- If alternatives are close, prefer the simpler/reversible one and instrument the decision.

## Product-quality check

A direction should be explainable without visual language. If the rationale collapses to “looks more premium/modern,” product strategy is not yet doing its job.
