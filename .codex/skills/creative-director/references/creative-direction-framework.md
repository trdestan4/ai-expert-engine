# Creative Direction Framework

A creative direction is a coherent system hypothesis connecting product truth, audience psychology, category context and visual/interaction behavior. It is not a palette + font + moodboard.

## Inputs

Start from product brief, brand assets/history, target audience context, category/competitor language, content types, trust requirements, device mix, localization, accessibility/performance limits and production reality.

Identify category codes in three groups:
- **expected:** conventions that support comprehension or trust;
- **overused:** familiar devices with weak differentiation;
- **ownable:** product/brand truths that can become a distinctive system.

## Direction anatomy

For each direction define:
1. **Strategic idea** — one sentence tying product truth to expression.
2. **Emotional target** — specific feeling and why it helps the user decide/act.
3. **Composition grammar** — grid, density, scale contrast, alignment, asymmetry, framing, whitespace and section rhythm.
4. **Typography behavior** — roles, voice, width/contrast/case/line-break behavior, not merely family names.
5. **Color behavior** — temperature, saturation, semantic roles, image compatibility, light/dark behavior.
6. **Visual media** — photography/3D/illustration/iconography/material/texture rules.
7. **Motion character** — tempo, continuity, depth, feedback vs narrative and rare signature moments.
8. **Signature device(s)** — one or a few repeatable brand/product-specific ideas.
9. **Content choreography** — how evidence, product explanation, comparison and CTA sequence creates momentum.
10. **Constraints** — mobile, reduced motion, localization, long content, performance, asset availability and CMS scalability.

## Build materially different options

Two directions are different only if concept/composition/behavior differ—not if the same template has another palette. One may be editorial and evidence-led, another tactile/product-led, another operational/data-led. Keep each credible to the same product.

## Evaluation

Compare directions on:
- product/audience fit;
- category comprehension and trust;
- differentiation and recognizability without logo;
- content resilience;
- scalability to dense/boring pages, not only hero;
- responsive recomposition;
- accessibility;
- performance/asset cost;
- implementation/maintenance realism.

Prototype signature moments early. A concept that only works in a static desktop hero is not a system.

## Artifacts and evidence

Useful evidence may include competitive code map, composition sketches, type/color/media studies, real-content page slice, mobile recomposition, motion storyboard and signature interaction prototype. Moodboards are supporting evidence only if they explain what is borrowed and transformed.

## Failure modes

Reject:
- luxury = black/navy + gold + serif;
- tech = neon blue/purple glow;
- SaaS = centered hero + floating dashboard + glass cards;
- arbitrary bento/grid just because it is trendy;
- 3D objects unrelated to product truth;
- fade-up-everything motion;
- “different” concepts that only change skin;
- signature interactions that hide information, trap scroll or collapse on mobile;
- a visual idea that disappears after the first viewport.

## Handoff

A creative direction should give specialists decision rules, not pixel dictatorship. Color/type/art/motion/UX specialists may refine the execution while preserving strategic idea and signature grammar. If technical/accessibility evidence breaks the concept, redesign the concept rather than forcing a degraded imitation.
