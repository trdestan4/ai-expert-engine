# Phase 01 Evals — Creative / Product

Each case should select the minimum expected skills.

| Prompt | Expected primary route | Must avoid |
|---|---|---|
| “Luxury dental clinic site yap, premium olsun.” | product-strategy → creative-director → ux-ui-design; specialist color/type if needed; anti-generic gate | direct black/gold or navy/gold mapping |
| “Bu palette kontrast ve dark mode sorunlarını düzelt.” | color-intelligence | full creative stack |
| “Logo kimliğini dijital sisteme çevir.” | brand-design; color/type only if required | ux-ui unless interface requested |
| “Site AI ile yapılmış gibi duruyor.” | anti-generic-design; creative-director if systemic rebuild required | trend replacement without rationale |
| “Hero scroll ile ürün dönüşsün.” | motion-direction + creative-director if concept unresolved | generic parallax/fade-only solution |
| “Mobilde checkout çok karışık.” | ux-ui-design | brand/color redesign |
| “Fotoğraflar farklı dünyalardan gibi.” | visual-art-direction | full identity rewrite |
| “Hangi font premium durur?” | creative context → typography-intelligence + anti-generic guard | automatic serif/prestige mapping |

## Quality evals

- Creative direction must explain category codes and visual grammar beyond hero styling.
- Anti-generic review must preserve useful UX conventions.
- Color output must include semantic roles and state/mode behavior, not only hex codes.
- Typography output must cover hierarchy, responsive behavior, glyph/performance constraints.
- UX/UI output must include real states and responsive re-composition.
- Visual art direction must define a repeatable visual bible.
- Motion must assign purpose and reduced-motion behavior.

## Token eval

Normal narrow requests should activate one primary skill and at most one supporting review. Full creative direction may activate product + creative + UX/UI plus only the specialists whose decisions are materially needed.
