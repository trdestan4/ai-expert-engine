# Phase 01 Routing — Creative / Product

Use the smallest owning skill set.

## Primary ownership

- Product outcome, audience, user jobs, scope priority → `product-strategy`
- Whole visual/experience thesis and specialist coordination → `creative-director`
- Identity assets/rules/logo system → `brand-design`
- Generic/template/AI cliché detection → `anti-generic-design`
- Palette, semantic color, modes/states → `color-intelligence`
- Font selection/type hierarchy/performance → `typography-intelligence`
- Photography/image/illustration/3D/icon visual bible → `visual-art-direction`
- Animation/scroll/transition behavior → `motion-direction`
- IA, flows, layout, components, responsive UI → `ux-ui-design`

## Typical routes

**New marketing site:** product-strategy → creative-director → ux-ui-design, then only needed color/type/art/motion specialists → anti-generic-design.

**New ecommerce creative direction:** product-strategy → creative-director → ux-ui-design + visual-art-direction + color/type as needed → anti-generic-design.

**“Make this premium”:** product-strategy if context unclear → creative-director → relevant specialists → anti-generic-design. Never route directly to color.

**Palette only:** color-intelligence. Add anti-generic-design only if rationale is cliché-driven.

**UI usability fix:** ux-ui-design only unless creative direction materially changes.

## Overlap prevention

Creative Director coordinates but does not write detailed specialist systems. UX/UI owns usable interface structure, not brand strategy. Brand Design owns identity, not page flow. Anti-Generic Design reviews/rejects; it does not become the primary art director unless a direction must be rebuilt.
