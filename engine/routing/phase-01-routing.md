# Phase 01 Routing — Creative / Product

Use the smallest owning skill set. Phase 01 defines product/design intent; Phase 10 owns specialist creative implementation/evidence when required.

## Primary ownership
- Product outcome, audience, user jobs, scope priority → `product-strategy`
- Whole visual/experience thesis and specialist coordination → `creative-director`
- Identity assets/rules/logo system → `brand-design`
- Generic/template/AI cliché detection → `anti-generic-design`
- Palette, semantic color, modes/states → `color-intelligence`
- Font selection/type hierarchy/performance → `typography-intelligence`
- Photography/image/illustration/3D/icon visual bible → `visual-art-direction`
- Animation/scroll/transition behavior and choreography intent → `motion-direction`
- IA, flows, layout, components, responsive UI → `ux-ui-design`

## Typical routes
**New marketing site:** `product-strategy` → `creative-director` → `ux-ui-design`, then only needed color/type/art/motion specialists → `anti-generic-design`; Phase 10 only if implementation crosses a specialist boundary.

**New ecommerce creative direction:** `product-strategy` → `creative-director` → `ux-ui-design` + visual-art/color/type as needed → `anti-generic-design`.

**“Make this premium”:** product context if unclear → `creative-director` → relevant specialists → `anti-generic-design`. Never route directly to a technology or color.

**Reference site/screenshot as inspiration or reconstruction:** `design-reconstruction` establishes evidence/design DNA; `creative-director` decides what should be preserved/adapted; `ux-ui-design` owns product-safe structure; Phase 10 implements.

**Motion language only:** `motion-direction`. If timeline/runtime code is requested, hand off to `animation-engineering` after intent is clear.

**3D concept/art direction:** `visual-art-direction`/`creative-director`; runtime is `threejs-webgl`, custom GPU effect is `realtime-shaders`, source/export pipeline is `three-d-asset-pipeline`.

**Palette only:** `color-intelligence`.

**UI usability fix:** `ux-ui-design` only unless creative direction materially changes.

## Overlap prevention
`creative-director` coordinates but does not write detailed specialist systems. `ux-ui-design` owns usable interface structure, not brand strategy. `brand-design` owns identity, not page flow. `motion-direction` is the motion designer, not the GSAP/Three implementation owner. Phase 10 never invents product/brand intent merely because a visual technology is requested. `anti-generic-design` reviews/rejects; it does not become the primary art director unless a direction must be rebuilt.
